# Publishing mathematics resources

This folder is the planned source library for the resource publishing pipeline. The existing HTML site remains the live source of truth until the new pipeline has been tested; adding files here does not publish them yet.

## Resource categories
Use the relevant class/subject folder:
- `class-11/`
- `class-12/`
- `applied-mathematics/`
- `articles/`

## Before publishing
1. Write original explanations and solutions wherever possible.
2. Verify every answer and every external/file link.
3. Use only material you have permission to publish.
4. Give each resource a unique ID and a unique planned URL.
5. Keep unpublished drafts out of the live site and sitemap.
6. Do not claim a resource is an official PYQ or official solution unless the source has been verified.

The pilot example under `examples/` is a design fixture only. It is not an actual past-paper resource and must not be presented as one.
