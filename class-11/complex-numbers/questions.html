SECTION A — 1 Mark Each

1.If \(4x+i(3x-y)=3+i(-6)\), then \(x,y\) are:
(a) \(x=3,y=4\)(b) \(x=\frac34,y=\frac{33}{4}\)(c) \(x=\frac43,y=\frac{33}{4}\)(d) \(x=3,y=\frac{33}{4}\)
2.The multiplicative inverse of \(z=a+ib\) is:
(a) \(\frac{a+ib}{a^2+b^2}\)(b) \(\frac{a-ib}{a^2+b^2}\)(c) \(\frac{a-ib}{a^2-b^2}\)(d) \(\frac{a+ib}{a^2-b^2}\)
3.The value of \((z+3)(\bar z+3)\) is:
(a) \(z\bar z+3(z+\bar z)+9\)(b) \(|z+3|^2\)(c) Both (a) and (b)(d) \(z^2+9\)
4.If \(a+ib=c+id\), then it is always true that:
(a) \(a^2+b^2=c^2+d^2\)(b) \(a=c,\ b=d\)(c) \(a+b=c+d\)(d) \(ac=bd\)
5.The value of the iota expression \(i^{45}+i^{-69}\) is:
(a) \(0\)(b) \(1\)(c) \(i\)(d) \(-i\)
6.For a non-zero complex number \(z\), the multiplicative inverse is:
(a) \(\bar z\)(b) \(\frac{\bar z}{|z|^2}\)(c) \(z\bar z\)(d) \(|z|^2\)
7.The least positive integral value of \(n\) for which \(i^n=1\) is:
(a) 2(b) 4(c) 6(d) 8
8.For the points represented by \(2,0\), \(4,2\), and \(p,3\) to be collinear, the value of \(p\) is:
(a) 4(b) 3(c) 2(d) 5
9.If \(|z|=1\), then \(\frac{1+z}{1+\bar z}\) is equal to:
(a) \(z\)(b) \(\bar z\)(c) 1(d) \(z^{-1}\)
10.If \(f(z)=\frac{7-z}{1-z^2}\) and \(z=1+2i\), find \(|f(z)|\).
(a) \(\frac{\sqrt5}{2}\)(b) \(\sqrt2\)(c) \(2\sqrt5\)(d) \(\frac12\)

SECTION B — 2 Marks Each

11.Evaluate \(\left[i^{19}+\left(\frac1i\right)^{25}\right]^2\).
12.Find \(1+i^2+i^4+i^6+\cdots+i^{20}\).
13.Find the number of non-zero integral solutions of \(|1-i|^x=2^x\).

SECTION C — 3 Marks Each

14.If \((a+ib)(c+id)(e+if)(g+ih)=A+iB\), prove that \((a^2+b^2)(c^2+d^2)(e^2+f^2)(g^2+h^2)=A^2+B^2\).
15.If \((x+iy)^3=u+iv\), prove that \(\frac ux+\frac vy=4(x^2-y^2)\).
16.Solve \(z+\sqrt2\,|z+1|+i=0\).

SECTION D — 5 Marks

17.If \(\alpha\) and \(\beta\) are different complex numbers with \(|\alpha|=|\beta|=1\), prove that \[\left|\frac{\beta-\alpha}{1-\bar\alpha\beta}\right|=1.\]

OR

If \(x+iy=\sqrt{\frac{a+ib}{c+id}}\), prove that \((x^2+y^2)^2=\frac{a^2+b^2}{c^2+d^2}\).
